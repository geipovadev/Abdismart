# Guía para instalar el agente en cada plataforma

Esta guía explica cómo conectar el agente al sitio web, WhatsApp e Instagram. Está escrita para acompañar al cliente durante el proceso. No es necesario que el cliente conozca programación.

## Antes de comenzar

El agente debe estar preparado antes de conectarlo a cualquier canal.

Confirma que ya existe:

- [ ] Una persona responsable del negocio.
- [ ] Una descripción aprobada del negocio.
- [ ] Una lista de servicios aprobada.
- [ ] Horarios, ubicaciones y requisitos confirmados.
- [ ] Una lista de temas que el agente no debe responder.
- [ ] Una persona encargada de atender los traspasos.
- [ ] Un medio de contacto humano.
- [ ] Autorización del cliente para conectar sus cuentas.

Si el cliente tiene un PDF con la información, debe revisarse y aprobarse antes de comenzar la instalación.

---

# Instalación en el sitio web

## Qué necesita el cliente

- Acceso administrativo al sitio web.
- Permiso para hacer cambios en la página.
- Nombre que utilizará el agente.
- Imagen o fotografía del agente, si desea mostrar una.
- Número de WhatsApp o medio de contacto humano.
- Política de privacidad del negocio.

## Paso 1: elegir dónde aparecerá

El cliente debe decidir:

- en qué páginas aparecerá el agente;
- si estará disponible en todo momento;
- qué nombre mostrará;
- qué mensaje verá la persona al abrirlo;
- a dónde se enviará a quien necesite atención humana.

Lo habitual es mostrarlo en la página principal y en las páginas de servicios.

## Paso 2: preparar la ventana de conversación

La persona instaladora añade al sitio:

- el botón para abrir el agente;
- la ventana donde se muestran los mensajes;
- el espacio para escribir;
- el formulario para dejar los datos de contacto;
- el enlace para hablar con el equipo.

El cliente revisa el nombre, los colores, la imagen y los textos visibles.

## Paso 3: conectar la información del negocio

La persona instaladora conecta la ventana con la información aprobada del cliente.

Se comprueba que:

- el agente se identifique correctamente;
- conozca los servicios activos;
- utilice horarios y ubicaciones vigentes;
- no muestre información de otro negocio;
- pueda pasar la conversación al equipo.

## Paso 4: preparar el registro de contactos

Cuando una persona desea continuar, el agente puede solicitar los datos mínimos necesarios.

El cliente debe decidir:

- qué datos necesita recibir;
- quién revisará los nuevos contactos;
- cuánto tiempo conservará esa información;
- cómo atenderá solicitudes para corregirla o eliminarla.

No se deben solicitar datos sensibles que no sean necesarios.

## Paso 5: probar antes de publicar

Realiza estas pruebas:

1. Abrir y cerrar el agente.
2. Enviar una pregunta general.
3. Preguntar por cada servicio.
4. Preguntar algo que no esté confirmado.
5. Solicitar hablar con una persona.
6. Completar el formulario de contacto.
7. Comprobar que el contacto llegue al lugar correcto.
8. Repetir la prueba desde un teléfono.

## Paso 6: publicar

Después de la aprobación del cliente, la persona instaladora publica los cambios.

Durante las primeras horas se comprueba que:

- la página cargue correctamente;
- el agente responda;
- el formulario funcione;
- el botón de contacto abra el destino correcto.

## Aprobación del sitio web

- [ ] El cliente aprobó el diseño.
- [ ] El agente funciona en computadora.
- [ ] El agente funciona en teléfono.
- [ ] Los contactos se guardan correctamente.
- [ ] El traspaso humano funciona.
- [ ] La política de privacidad está disponible.

# Instalación en WhatsApp

## Qué necesita el cliente

- Una cuenta comercial de Meta.
- Una cuenta de WhatsApp Business.
- Un número comercial que pueda conectarse.
- Acceso de administrador a las cuentas.
- Nombre comercial aprobado para WhatsApp.
- Una persona que atenderá los traspasos.

## Paso 1: confirmar el número

El cliente elige el número que utilizará el agente.

Antes de continuar, confirma:

- que el número pertenece al negocio;
- que el cliente puede recibir el código de verificación;
- que no está conectado a otro sistema incompatible;
- que el nombre comercial corresponde al negocio.

## Paso 2: preparar la cuenta de Meta

La persona administradora entra a la cuenta comercial de Meta y selecciona el negocio correcto.

Después:

1. Abre la configuración de WhatsApp.
2. Agrega o selecciona la cuenta del negocio.
3. Registra el número comercial.
4. Completa la verificación solicitada por Meta.
5. Confirma el nombre que verán las personas.

El cliente debe revisar que no se esté utilizando accidentalmente la cuenta de otro negocio.

## Paso 3: autorizar la conexión

Meta entrega varios datos privados que permiten recibir y responder mensajes.

La persona instaladora guarda esos datos de forma segura. No deben enviarse en grupos, capturas ni documentos compartidos.

El cliente no necesita copiar esos datos en la información del agente.

## Paso 4: registrar el lugar donde llegarán los mensajes

La persona instaladora prepara una dirección segura para recibir los mensajes de WhatsApp.

Después:

1. Copia esa dirección en Meta.
2. Crea una palabra de verificación.
3. Guarda la misma palabra en el sistema del agente.
4. Solicita a Meta comprobar la conexión.
5. Activa la recepción de mensajes.

La comprobación debe finalizar correctamente antes de continuar.

## Paso 5: conectar el agente

La persona instaladora enlaza WhatsApp con la información aprobada del negocio.

Se define:

- qué mensajes responderá automáticamente;
- cuándo debe intervenir una persona;
- cómo se guardará el contexto de la conversación;
- cómo se atenderán las notas de voz;
- qué ocurrirá si alguien solicita no recibir más mensajes.

## Paso 6: probar desde otro número

No hagas la prueba únicamente desde el mismo número del negocio.

Desde otro teléfono:

1. Envía un saludo.
2. Pregunta quién es el negocio.
3. Pregunta por un servicio.
4. Envía una nota de voz.
5. Pregunta un precio no publicado.
6. Solicita hablar con una persona.
7. Comprueba que el equipo reciba el aviso.
8. Envía una solicitud para no recibir más mensajes.

## Paso 7: activar y observar

Cuando las pruebas sean correctas, se activa el número para el público.

Durante los primeros días revisa:

- respuestas que no resolvieron la consulta;
- notas de voz que no se entendieron;
- conversaciones que necesitaron una persona;
- mensajes duplicados;
- preguntas frecuentes que todavía no están documentadas.

## Aprobación de WhatsApp

- [ ] Meta verificó el número.
- [ ] La conexión fue aceptada.
- [ ] Los mensajes llegan al agente.
- [ ] El agente puede responder.
- [ ] Las notas de voz funcionan.
- [ ] El traspaso humano funciona.
- [ ] Las solicitudes para no recibir mensajes se respetan.
- [ ] No existe otro asistente respondiendo el mismo número.

# Instalación en Instagram

## Qué necesita el cliente

- Una cuenta profesional de Instagram.
- Acceso de administrador a la cuenta.
- Una cuenta comercial de Meta.
- Permiso para conectar Instagram con la aplicación del agente.
- Una persona que atenderá los traspasos.

Una cuenta personal debe convertirse en profesional antes de continuar.

## Paso 1: revisar automatizaciones existentes

Antes de conectar el agente, revisa si Instagram ya tiene:

- respuestas automáticas;
- mensajes de bienvenida;
- otro asistente;
- una conexión con una herramienta externa.

Si existe otro asistente, debe detenerse o coordinarse. Dejar dos asistentes activos puede producir respuestas duplicadas o incorrectas.

## Paso 2: agregar Instagram en Meta

La persona administradora entra a la aplicación de Meta que utilizará el agente.

Después:

1. Abre la sección de Instagram.
2. Añade la cuenta profesional del cliente.
3. Inicia sesión con la cuenta correcta.
4. Autoriza la administración de mensajes.
5. Confirma que la cuenta aparezca conectada.

## Paso 3: generar la autorización para responder

Meta permite generar una autorización para la cuenta conectada.

La persona administradora:

1. Selecciona la cuenta profesional.
2. Genera la autorización.
3. Inicia sesión si Meta lo solicita.
4. Acepta el permiso para administrar mensajes.
5. Entrega el dato a la persona instaladora por un medio seguro.

No debe confundirse con la clave de verificación ni con el número que identifica la aplicación.

## Paso 4: identificar correctamente la cuenta

Meta muestra varios números. Para conectar el agente se necesita el número que aparece junto a la cuenta de Instagram.

No debe utilizarse:

- el número de la aplicación;
- el número de WhatsApp;
- el nombre de usuario con arroba.

La persona instaladora guarda el número correcto de la cuenta.

## Paso 5: registrar el lugar donde llegarán los mensajes

La persona instaladora prepara una dirección segura para Instagram.

Después:

1. Copia esa dirección en Meta.
2. Crea una palabra de verificación exclusiva.
3. Guarda la misma palabra en el sistema del agente.
4. Solicita a Meta comprobar la conexión.
5. Activa la recepción de mensajes privados.

## Paso 6: guardar la clave privada de Instagram

La aplicación de Instagram tiene una clave privada propia. La persona instaladora debe guardarla de forma segura para comprobar que los mensajes realmente vienen de Meta.

No debe utilizarse la clave de WhatsApp si Instagram muestra una diferente.

## Paso 7: conectar el agente

La persona instaladora enlaza Instagram con la información aprobada del negocio.

Se comprueba que:

- utilice la cuenta correcta;
- pueda responder mensajes escritos;
- pueda comprender notas de voz;
- ignore confirmaciones de lectura y reacciones;
- no responda sus propios mensajes;
- pase la conversación al equipo cuando corresponda.

## Paso 8: probar desde otra cuenta

Desde una cuenta diferente:

1. Envía “Hola”.
2. Pregunta quién es el negocio.
3. Pregunta por un servicio.
4. Envía una nota de voz corta.
5. Pregunta algo que el agente no conozca.
6. Solicita hablar con una persona.
7. Confirma que no llegue una respuesta de un asistente anterior.

## Paso 9: activar para el público

La aplicación debe estar habilitada para atender personas reales, no solo administradores o personas de prueba.

Después de activarla, repite una prueba desde una cuenta que no participe en la administración.

## Aprobación de Instagram

- [ ] La cuenta es profesional.
- [ ] La cuenta correcta está conectada en Meta.
- [ ] Se autorizó la administración de mensajes.
- [ ] Meta aceptó la dirección de conexión.
- [ ] Los mensajes llegan al agente.
- [ ] El agente responde texto.
- [ ] El agente comprende notas de voz.
- [ ] El traspaso humano funciona.
- [ ] No existe otro asistente activo.
- [ ] Se probó desde una cuenta externa.

# Instalación en varios canales

Cuando un cliente utiliza sitio web, WhatsApp e Instagram, sigue este orden:

1. Aprobar la información del negocio.
2. Preparar el agente central.
3. Instalarlo en el sitio web.
4. Probar la atención y el traspaso.
5. Conectar WhatsApp.
6. Probar texto y notas de voz.
7. Conectar Instagram.
8. Desactivar asistentes anteriores.
9. Probar todos los canales desde cuentas externas.
10. Obtener la aprobación final del cliente.

Los tres canales deben utilizar la misma información aprobada. Cuando cambie un horario, servicio o política, debe actualizarse la fuente central para evitar respuestas diferentes entre plataformas.

# Entrega final al cliente

Al terminar, entrega un resumen con:

**Nombre del negocio:**  
**Nombre del agente:**  
**Persona responsable:**  
**Sitio web activo:** Sí / No  
**WhatsApp activo:** Sí / No  
**Instagram activo:** Sí / No  
**Contacto humano:**  
**Horario de atención humana:**  
**Fecha de aprobación:**  
**Fecha de la última prueba:**  
**Información pendiente:**  

No incluyas contraseñas ni claves privadas en el documento de entrega.

---

# Cuándo considerar terminada la instalación

La instalación está completa cuando:

- [ ] El cliente aprobó la información.
- [ ] Cada canal seleccionado recibe mensajes.
- [ ] El agente responde con información correcta.
- [ ] Las notas de voz funcionan donde corresponde.
- [ ] El agente reconoce cuando no sabe algo.
- [ ] El traspaso humano funciona.
- [ ] No hay respuestas duplicadas.
- [ ] No aparece información de otro negocio.
- [ ] El cliente sabe cómo solicitar actualizaciones.
- [ ] Existe una fecha para la próxima revisión.
