# Incorporación de documentos del cliente

## Documentos admitidos

Usar esta ruta cuando el cliente entregue PDF, Word, texto, folletos, catálogos, preguntas frecuentes, políticas o documentos operativos.

Para PDF, usar la skill de PDF disponible. Leer el documento completo y revisar visualmente las páginas cuando existan tablas, diagramas, formularios o información cuya posición cambie el significado.

## Flujo

1. Confirmar que el cliente autoriza usar el documento para preparar el agente.
2. Identificar nombre, fecha y versión del documento.
3. Leer todo el contenido relevante, incluidas tablas y notas.
4. Separar la información en:
   - identidad del negocio;
   - público y cobertura;
   - servicios;
   - inclusiones y exclusiones;
   - precios;
   - horarios y ubicaciones;
   - requisitos y políticas;
   - preguntas frecuentes;
   - contacto humano;
   - límites del agente.
5. Mantener la página o sección de origen de cada dato.
6. Marcar como pendiente toda la información extraída.
7. Detectar contradicciones, datos antiguos, campos vacíos y lenguaje ambiguo.
8. Mostrar un resumen sencillo al cliente.
9. Preguntar únicamente por contradicciones, datos faltantes y decisiones necesarias.
10. Solicitar aprobación explícita antes de usar la información en el agente.

## Reglas

- No asumir que un PDF es correcto solo por ser un documento formal.
- No convertir afirmaciones publicitarias en hechos verificables.
- No inventar datos que el documento omita.
- No mezclar contenido de documentos con versiones o fechas diferentes sin indicarlo.
- No usar expedientes, datos clínicos, información de pacientes, contraseñas ni datos de pago.
- No aprobar automáticamente información extraída.
- Si el PDF es una imagen escaneada, aplicar lectura visual o reconocimiento de texto y advertir cuando una parte no sea legible.

## Resumen para aprobación

Presentar:

- lo encontrado;
- la fuente de cada bloque;
- información que parece desactualizada;
- contradicciones;
- datos faltantes;
- información sensible excluida;
- preguntas que aún debe responder el cliente.

Preguntar: “¿Apruebas esta información para preparar el agente?”

Solo después de una respuesta afirmativa cambiar los datos confirmados a aprobados.
